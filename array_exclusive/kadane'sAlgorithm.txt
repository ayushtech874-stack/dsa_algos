/*
Maximum Subarray Sum
Subarray : contigous part of array

arr[] = [-2 -3 4 -1 -2 1 5 -3]

Bruteforce : take three loops , point one element take sum of all subarrays related to it and compare TC = O(N3)

Better : Take two loops and do the same TC = O(N2)

Optimal : Kadane's Algorithm
It suggests that there is no point of carrying negative sum (sum<0) forward as it will just hamper my sum negatively

PseudoCode :

int maxi = INT_MIN;
int sum = 0;
for(int i = 0 ; i<n ; i++)
{
    sum = sum + arr[i];
    if( sum > maxi )
    {
        maxi = sum;
    }
    if(sum<0)
    {
        sum=0;
    }
}
return maxi;

// So here we are just returning the maximum subarray sum and not the subarray itself
The question may differ so do it accordingly 

TC = O(N)   SC = O(1)

*/
