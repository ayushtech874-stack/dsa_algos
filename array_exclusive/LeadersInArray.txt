/*
Leaders in the array : 
PS : Everything on the right side of a given element is smaller than that element or 
doesnt exist
We need to return the leaders in the same order as it is in given array 

arr[] = [10 , 22 , 12 , 3 , 0 , 6]

BruteForce : Pick one element and do the linear search on that and check for the condition
whether Everything on the right of its is smaller or not and with that add it in the 
answer list 
TC = O(N^2)
SC = O(N)   // to store the answer 

Optimal : Stand on one element at the right 
and check for the greatest element on the right and compare the iterated element directly
with it , if it is still greater than its leader element else its not 

PseudoCode : 

int maxi = INT_MIN;
vector<int> ans(n,0);
for(int i = n-1 ; i>=0 ; i--)
{
    if(arr[i] > maxi)  // if the selected element > maximum element then its leader
    {
        ans.add(arr[i]);
    }
    maxi = max(maxi , arr[i]);
}
// since we are traversing backwards to return in given order we need to reverse
reverse(ans.begin() , ans.end());
return ans;

TC = O(N)
SC = O(N) to return answer
*/
