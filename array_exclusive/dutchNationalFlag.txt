This is the standard algorithm known as Dutch National Flag algorithm
It is used to sort the array of 3 differnt identity in It

Optimal : Dutch National Flag algorithm
Take 3 pointers low mid high
Rules:  
1. Everything which is 0 [0 to low-1] should be kept at extreme left 
2. Everything which is 1 [low to mid-1] should be kept in middle
3. Everything which is 2 [high+1 to n-1] should be kept in extreme right 

int low = 0;
int mid = 0;
int high = n-1;
while(mid<=high)   // when mid crosses high we know that the area to be sorted is done 
{
    if(arr[mid]==0)
    {
        swap(a[low].a[mid]);  //shrink left side
        low++;
        mid++;
    }
    else if(arr[mid]==2)
    {
        swap(a[high],a[mid]);   // shrink right side
        high--;
    }
    else if(arr[mid]==1)
    {
        mid++;
    }
}


TC = O(N)
SC = O(1)

Real life problems : Traffic signal where 3 colors are there
Sorting 3 balls (give number to each ball)
Data classification on basis of priority
